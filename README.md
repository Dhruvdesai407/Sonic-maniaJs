# Sonic Mania JS Game

A simple Sonic-themed endless runner game built with Kaplay.js.

## Live Demo

[Play the game here](https://Dhruvdesai407.github.io/Sonic-maniaJs/)

## Installation and Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Dhruvdesai407/Sonic-maniaJs.git
   cd Sonic-maniaJs
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
   The game will be accessible at `http://localhost:5173/` (or another port if 5173 is in use).

## Deployment

To deploy the game to GitHub Pages, run:

```bash
npm run deploy
```

This will build the project and push it to the `gh-pages` branch.
